# ShopNova

ShopNova is a full-stack e-commerce product catalog application created as a Web Development Capstone Project.

## Features

- Modern responsive e-commerce interface
- Modular frontend architecture
- Client-side routing
- Product search
- Product details
- Shopping cart
- LocalStorage cart persistence
- Express.js backend
- REST API
- Admin authentication
- Admin dashboard
- Add products
- Edit products
- Delete products
- Product stock management
- Product categories
- JSON-based demo database
- Responsive mobile interface
- Lazy-loaded product images
